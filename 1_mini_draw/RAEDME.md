# 1. MiniDraw: A Small Drawing Tool

The main focus of this assignment is object-oriented programming.

MiniDraw is an interactive drawing applet that supports graphic elements such as lines (Line), ellipses (Ellipse), rectangles (Rectangle), polygons (Polygon), and freehand drawing (Freehand).

Each graphic element is **encapsulated** in a class (object), and all elements **inherit** from a parent class. Drawing functions are called using class **polymorphism**.

The class diagram is provided in the report.
