# 4. Surface Parameterization - Tutte Parameterization

This program implements the Tutte mesh parameterization method introduced in the paper [Floater1997](https://www.cs.jhu.edu/~misha/Fall09/Floater97.pdf), testing two weight configuration approaches:

- Uniform weights
- Cotangent weights

Texture mapping tests were conducted to validate the implementation.

The report includes visualization results of the parameterization effects.
